# 心镜拾光：项目材料索引

本目录用于记录个人作品集项目“心镜拾光”的产品、架构、实施与审查材料。

## 项目定位

> 一款以图像卡片为交互媒介、帮助用户整理困扰并形成小行动的微信小程序。它提供的是娱乐性自我探索，不对未来作确定性断言，也不替代医疗、心理、法律或金融专业意见。

项目属性：**非商业化个人练手项目 × C 端 AI 内容工具 × 可上线演示的 0-1 MVP**。

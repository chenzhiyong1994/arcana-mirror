# 心镜拾光：v0.3 高保真体验与解读减负

## 1. 目标

在不接入 CloudBase、账号或真实 AI 的前提下，把已跑通的本地功能闭环升级为可展示、可收集、可持续阅读的高保真微信小程序体验。视觉需要让卡牌成为绝对主角；内容需要保留反思深度，但不能让用户在翻牌后的兴奋点立刻掉进长文墙。

## 2. 内容审计结论

v0.2 的信息并非每一项都无价值，问题是四个领域同时出现：单牌会连续读四个维度，三牌会形成十二个领域段落，再叠加总结、综合、问题与行动。用户已经在提问页选择主题，因此其余三个领域多数时候是无关负担。

v0.3 决策：

- 保留正逆位依据、情境解释、主题洞察、综合提示、反思问题和行动；
- 每张牌只展示当前主题的一条洞察；
- 三牌一次只展开一张，点牌切换，不纵向堆叠三份全文；
- 牌义依据与关键词默认折叠，供需要核对的用户展开；
- 总结先于解释，行动晚于综合，按照“先理解，再核对，最后行动”的顺序接收；
- 原问题默认折叠；第一眼线索、逐牌解读、三牌串联、反思与行动使用连续章节编号和独立容器，逐牌内部再以“牌面直觉—落到现实—可选牌义”分层，避免连续正文形成长文墙；
- 旧 v0.2 已保存记录继续兼容，不做破坏性迁移。

这一结构也符合常见三牌法的使用方式：先为三个位置定义清晰角色，再把牌连成一条进程，并落到一个行动，而不是平铺所有可能领域。参考：[Situation / Challenge / Advice](https://www.pageofcards.com/spreads/three-card-row/situation-challenge-advice)、[Biddy Tarot 的简洁三牌结构](https://biddytarot.com/podcast/btp10-never-fail-3-card-spreads/)。外部材料只用于验证信息结构，不用于复制具体牌义或文案。

## 3. 视觉基线

方向名：**黑金典藏 · 镜廊仪式**。

- 色彩：深墨黑与暖黑为底，旧金作为信息层级和反馈，不使用高饱和渐变；
- 材质：细微纸张、金箔和暗部层次，避免纯黑扁平与廉价发光；
- 品牌：使用 L5“繁饰日蚀心镜”Logo，保留手绘卷草、镜框与旧金质感；
- 卡牌：使用 A“仪式典藏”正式卡面和统一卡背，编号与名称由界面叠加；
- 排版：中文标题偏编辑感，英文眉题承担节奏，正文优先可读性；
- 容器：用细线、留白、微弱内外阴影建立层次，减少同质化圆角卡片。

## 4. 关键交互

### 首页

Logo 与主标题建立品牌记忆；每日一牌为主视觉，单牌/三牌以两张不同密度的入口呈现；图鉴进度和最近历史作为回访线索，不争夺主任务。辅助说明保持一行或短句，首页分享使用标题区的小号次级入口。

### 提问

牌阵与主题先选，问题后写；每次选择提供轻震动和金色状态变化。安全改写或阻断仍发生在抽牌前。

### 抽牌

未翻开时统一卡背；翻开使用真实 3D 双面旋转，伴随克制光晕、闪光与进度点。三牌按顺序揭示，最后一次翻牌后进入结果。已经翻开的牌可再次点击，进入带旧金框、暗场聚光与正逆位信息的沉浸大图。

### 结果

牌面先于文本。三张牌既是结果展示，也是逐牌阅读导航；当前牌具有清晰高亮。点击非当前牌切换解读，点击当前牌进入沉浸大图，避免一个手势承担两个不明确的结果。详情层默认只显示情境解释与所选主题洞察，依据可展开；两者用边框、底色和留白分组。页面末尾把反思问题与微行动合成收束卡，分享区只保留生成按钮和“不展示原问题”提醒。

### 图鉴与历史

图鉴强调已解锁的收藏感和未解锁的神秘感；详情用底部面板承载，点击详情卡面可继续进入与抽牌、结果页一致的沉浸鉴赏大图。历史使用紧凑分组列表，卡面、类型/日期、名称与操作各自成层；重读与删除使用等宽、易点击但克制的双按钮。AI、敏感信息和本地数据边界分别放在相关流程中，不设置独立设置页。

## 5. 动效与性能边界

- 关键动效只服务于出现、选择、翻牌和揭示，不持续抢占注意力；
- 使用小程序原生 CSS 变换，不引入重型粒子、Canvas 渲染或动画依赖；
- 卡面由 1024×1536 正式原图确定性生成 640×960 高清 JPEG，兼顾鉴赏大图细节与本地包体；Logo 使用 512×512 JPEG；
- 轻震动是附加反馈，游客模式下的工具模拟警告不影响核心流程；
- 文本和操作不依赖颜色单独表达，按钮保持可点击尺寸和明确文案。

## 6. 验收标准

- 首页、提问、抽牌、结果、图鉴、历史六页在微信开发者工具中无页面异常；
- 未翻卡统一显示卡背，正面显示真实卡面、牌名、编号和朝向；
- 翻开后与结果页均能点击当前牌查看大图，可从关闭按钮或暗处返回原流程；
- 三牌可依次翻开；结果页先展示原始困扰和第一眼线索，再把真实牌阵与“逐张看清”正文放入同一交互区，卡面直接承担切换与当前牌反馈，并保留阅读进度和当前牌大图入口；
- 首屏不出现多领域长文墙，所选主题与展示内容一致；
- success、timeout、invalid、unsafe 四种模拟模式保持受控结构；
- 类型检查与自动化测试通过，旧 v0.2 历史可读；
- 不接入 CloudBase、真实 AI、微信云身份或账号系统。

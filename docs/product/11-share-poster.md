# 心镜拾光：首页与结果分享图增量

## 1. 目标与边界

个人主体小程序无法依赖朋友圈分享入口，因此提供两类“生成分享图”：

- 首页通用图：介绍“心镜拾光”和核心体验，不关联任何一次解读；
- 结果图：把本次牌面、第一眼线索和微行动合成为竖版海报。

两类图片都可保存、转发，并嵌入可长按识别的小程序码。

分享图不是历史同步或公开解读链接：

- 不上传 Reading，不生成公开详情页；
- 不默认展示用户原问题，避免私密困扰随图片传播；
- 只使用已经通过结构与安全校验的摘要、行动建议和卡牌事实；
- 小程序码固定打开首页，不携带 Reading ID 或用户标识；
- 保留“娱乐性自我探索、不替代专业意见”的产品边界。

## 2. 用户流程

1. 用户在首页点击“分享”，或在结果页点击“生成分享图”；
2. 客户端调用 CloudBase `api` 云函数获取与当前版本一致的小程序码；
3. 客户端 Canvas 在本地合成海报，展示预览；
4. 用户可长按图片识别小程序码、使用图片菜单转发，或保存到系统相册。

生成失败不影响阅读、自动历史或其他页面操作。相册权限只在用户主动点击“保存到相册”时申请。

## 3. 视觉与内容

- 延续“黑金典藏 · 镜廊仪式”：深墨底、旧金双线框、克制的顶部光晕；
- 首页通用图使用 Logo、产品短句和卡背组合，不包含 Reading；结果图单牌使用居中大卡，三牌使用等宽联排；
- 小阿尔卡那在 Canvas 内继续叠加唯一共享正面框、顶部牌阶和双语铭牌；
- 正逆位旋转整张成牌，不改变牌面事实；
- 首页通用图固定包含品牌名、产品短句、卡背、小程序码与免责声明；
- 结果图固定包含品牌名、解读主题与日期、卡牌、第一眼线索、微行动、小程序码与免责声明；
- 码区保留浅色静区，不叠加纹理或透明效果，保证长按识别成功率。

## 4. 验收标准

- 首页通用图、单牌结果图、三牌结果图以及大/小阿尔卡那混合组合均能正确成图；
- 小牌框体、牌阶、名称和正逆位与结果页一致；
- 两类海报均不包含 `question`、Reading ID、模型原始响应或本地历史；
- 开发版、体验版、正式版分别生成对应 `envVersion` 的小程序码；
- 真机长按海报能识别并打开首页，保存相册在允许/拒绝权限两条路径下反馈明确；
- 云函数未部署、网络失败或码生成失败时显示可恢复提示，不中断结果页；
- `npm run typecheck`、`npm test` 与 `npm run validate:assets` 通过。

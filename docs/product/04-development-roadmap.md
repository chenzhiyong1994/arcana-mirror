# 阿卡纳心镜：开发路线与作品集计划

## 1. 当前路线原则

- 当前阶段只完成微信开发者工具可运行的本地 MVP；
- 前端只提供低保真、可操作的功能界面，视觉与精细交互独立推进；
- 本地 Repository 和模拟 Provider 先跑通完整闭环，云端与真实模型以后通过适配器替换；
- 日记、心情、自由笔记和可编辑行动不在产品范围内；
- 安全分类、结构校验、失败降级、历史删除和自动化测试属于 P0；
- CloudBase、微信云身份、账号和真实 AI 必须收到独立指令后才启动。

## 3. 本地 MVP 功能范围

### P0：本轮闭环

- 每日一牌：按 Asia/Shanghai 自然日唯一，首次抽取后自动进入本地历史；
- 主题提问：感情、人际、事业、自我四类，5—200 字；
- 输入安全：允许、建议改写、专业边界、自伤/伤人阻断、操纵/违法阻断；
- 单牌抽取：22 张大阿卡纳、正逆位、单次抽取结果固定；
- 模拟解读：成功、超时、非法结构、不安全输出四种测试模式；
- 输出校验：字段、长度、牌面、朝向、固定免责声明与不安全措辞；
- 失败降级：任何 Provider 异常或输出不合规都返回受控基础牌义；
- 本地历史：主题解读默认不保存，明确选择后才保存；
- 历史管理：详情、单条删除和清空全部；
- 设置说明：明确本地数据、模拟数据和无账号边界；
- 自动化验证：领域、安全与结构契约测试。

### 明确后置

- CloudBase、云函数、云数据库和跨设备同步；
- 微信云身份、显式登录、用户名或密码账号；
- 真实 AI、Prompt 版本管理、模型评估集与供应商切换；
- 三牌解读、78 张完整牌组、回访、分享图和数据趋势；
- 高保真视觉、复杂动效、声音与震动；
- 支付、会员、广告、社区、私信、真人占卜师和通用 Agent。

## 4. 本地验收路径

1. 每日一牌：首次抽取生成记录，同一天再次进入复用同一个 Reading；
2. 正常主题：安全检查通过，抽牌，模拟成功，结果默认不在历史，主动保存后可查看；
3. 改写主题：确定性预测或专业问题先显示受控改写，采用后继续；
4. 高风险主题：危机、自伤伤人、操纵、违法或赌博在抽牌前阻断；
5. 降级主题：分别切换超时、非法结构、不安全输出，均得到基础牌义降级；
6. 数据管理：未保存主题离开即丢弃，历史可单删，设置页可清空全部。

详细操作与验证记录见 `docs/development/local-mvp-validation.md`。

## 5. 未来替换边界

页面依赖 `ReadingService`，领域服务依赖 `ReadingRepository` 与 `InterpretationProvider`。未来接入 CloudBase 和真实 AI 时，优先新增实现并替换组装层，不改 Reading、Card、Interpretation、安全分类和页面流程。

云端历史若启用，可使用云函数上下文中的 OpenID 做数据归属，但这不等于建设用户名/密码账号系统。本地历史是否迁移到云端必须另行设计，当前默认不迁移。

## 6. 质量门禁

| 门禁 | 当前阶段标准 |
| --- | --- |
| 工程 | TypeScript 类型检查通过，微信开发者工具能加载用户代码和页面 |
| 领域 | 每日唯一、22 张牌可达、显式保存、删除与清空符合规则 |
| 安全 | 高风险输入在抽牌前阻断，模型式输出失败后不直接展示 |
| 数据 | 无密钥、无账号、无云依赖；问题不写日志；未保存主题不进入历史 |
| 降级 | timeout、invalid、unsafe 三种模式均返回受控结构 |
| 范围 | 无日记字段，无真实 AI 或 CloudBase 的隐藏依赖 |

## 7. 后续作品集表达原则

只有在对应能力实际完成并留下验证证据后，才能写入简历或案例。当前可准确描述为：使用 TypeScript 构建微信原生小程序的本地领域闭环，通过 Repository/Provider 适配器、输入安全分类、结构化输出校验和受控降级验证核心产品路径。不得提前宣称已完成云端部署、真实模型评估、跨设备账号或生产用户验证。

# 分享图云函数部署与验收

首页通用海报与结果页海报均由客户端本地 Canvas 合成；小程序码由 `cloudfunctions/api` 的 `share.code` action 通过微信云调用生成。仓库不保存 AppSecret，也不把用户问题发送给该云函数。

## 部署

1. 在微信开发者工具中选择与本地 `apps/miniprogram/config/cloud.ts` 一致的 CloudBase 环境；
2. 右键 `cloudfunctions/api`，选择“上传并部署：云端安装依赖”；
3. 在云开发控制台确认 `api` 云函数已部署，且云调用权限包含 `wxacode.getUnlimited`；
4. 分别用开发版或体验版生成海报；正式发布后再验证正式版小程序码。

`config.json` 已声明云调用权限，`package.json` 固定 `wx-server-sdk` 版本。云函数只接受 `share.code`，小程序码固定打开 `pages/home/index`；客户端传入的 `envVersion` 只允许 `develop`、`trial`、`release`。

### 当前状态

2026-07-29 已通过微信开发者工具将 `api` 上传至维护者自有环境，采用云端安装依赖；开发版首页已成功获取小程序码并完成通用海报预览。首次部署后 OpenAPI 权限存在短暂生效窗口，等待权限传播后复测成功。具体环境标识不进入开源仓库。

## 真机验收

- 首页生成一次通用图，确认只有品牌介绍、卡背和小程序码，没有 Reading 内容；
- 单牌与三牌结果图各生成一次，覆盖至少一张小阿尔卡那和一次逆位；
- 检查两类海报均不含用户原问题；结果图的卡名、牌阶、朝向、摘要与行动建议正确；
- 在海报预览中长按识别小程序码，确认打开对应版本首页；
- 点击“保存到相册”，分别验证首次授权、拒绝后去设置、已授权三条路径；
- 断网或停用 `api` 云函数后重试，确认只提示生成失败，当前解读仍可继续使用。

开发版小程序码只对具备开发权限的微信账号可用；面向普通用户的分享验收必须使用体验版或正式版。

## 依赖审计说明

截至 2026-07-29，`wx-server-sdk@4.0.2` 是 npm 发布的最新版本，但其 `@cloudbase/node-sdk` 与数据库传递依赖仍触发 6 项 `npm audit` 告警（1 项 moderate、5 项 high），上游尚无不降级 SDK 的自动修复版本。当前 action 不调用数据库、不接收 URL、只接受枚举版本并使用固定微信接口与页面路径，以缩小实际暴露面；在上游修复前，不应把该云函数扩展为接收任意 URL 或通用透传参数的接口。

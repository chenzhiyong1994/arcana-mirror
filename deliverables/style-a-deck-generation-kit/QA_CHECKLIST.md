# 生成验收清单

## 单张牌硬门禁

任何一项失败都必须重做，不能以局部美观抵消语义缺失：

- [ ] 文件名与 `card-specs.json` 完全一致；
- [ ] PNG，1024×1536，2:3，严格正视；
- [ ] 无标题、编号、Logo、水印、伪文字、外边框；
- [ ] 顶部 138 px 与底部 215 px 内没有关键人物、手势或道具；
- [ ] `requiredSymbols` 全部可见且关系正确；
- [ ] `forbiddenFailures` 均未出现；
- [ ] 主体轮廓在约 170×255 px 缩略图下仍可辨认；
- [ ] 手部、持物、肢体、动物数量和方向合理；
- [ ] 只使用 A 的煤黑/石墨灰/旧金语言，没有彩色、霓虹、玻璃或 3D；
- [ ] 金色只服务关键象征和轮廓，没有全图平均发亮；
- [ ] 颗粒未吞没面部、手势和核心小物；
- [ ] 不复制商业牌组或参考图的具体人物、服装、文字和构图。

## 语义审查顺序

1. 先遮住风格，只问“这张牌是否能被主流牌义识别”；
2. 再检查人物—道具—姿态—场景之间的关系；
3. 再检查 A 风格一致性；
4. 最后检查收藏感与细节。

若第 1 或第 2 步失败，直接重做，不进入美术微调。

## 整套一致性门禁

- [ ] 22 张文件齐全，编号 0—XXI 无遗漏、无重复；
- [ ] 人物平均尺度、黑位、旧金色相、颗粒密度和构图边距一致；
- [ ] 不同牌具有不同主形状，不能全是中央披风人物或山顶场景；
- [ ] 每张牌只有一个最强视觉锚点；
- [ ] 统一正面框仅有一份，并用于全部预览；
- [ ] 统一卡背仅有一份，水平/垂直/180° 对称检查通过；
- [ ] 22 张纯插画均可支持前端正位与 180° 逆位显示；
- [ ] 预览中的编号、中文名、英文名与 `card-specs.json` 一致；
- [ ] 没有模型水印、生成签名、随机文字或潜在侵权元素。

```markdown
- 技术规格：通过/不通过（说明）
- 已知问题：无 / ...
```

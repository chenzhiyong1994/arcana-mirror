# A 风格统一生成合同

## 参考图输入规则

生成所有牌面时，将 `references/style-a-front-back-reference.png` 作为 **视觉与材质参考**。它只负责风格，不负责当前牌的语义。

仅生成 IX 隐士时，额外加入 `references/hermit-semantic-anchor.png`，角色设为 **牌义与人物关系参考**。

不要使用本项目之外的塔罗牌图片、具体艺术家作品或商业牌组作为参考。

## 牌面插画统一 Prompt

下列文本必须作为每张牌 Prompt 的公共前缀，并与 `CARD_PROMPTS.md` 中对应牌的“牌义块”拼接：

> 为微信小程序生成一张原创大阿尔卡那牌的纯牌面插画层，竖版 2:3，1024×1536，严格正视平面构图。视觉锁定 A“仪式典藏”：煤黑与石墨灰为绝对主色，旧金只用于关键轮廓、象征物高光和少量视觉引导；手工铜版/木刻般的黑灰线刻，深色纤维纸，轻微颗粒油墨、刮擦与不均匀断金箔，哑光、克制、神秘、庄重、可收藏。主体占画面高度约 55%—65%，轮廓在手机缩略图中仍然清楚；前景、中景、背景层级明确，留出顶部 9% 编号安全区和底部 14% 标题安全区，关键人物、手势和道具不得进入安全区。生成内容只包含当前牌的原创人物、道具、姿态、场景与象征，不继承参考图中的隐士人物或山峰构图。输出纯插画，不生成外边框、编号、中文名、英文名、解释文字、Logo、水印或任何可读/伪造字符。

随后拼接对应牌义块，再拼接下面的全局负面块。

## 全局负面 Prompt

> 禁止：彩色主调、蓝紫霓虹、亮黄铜、镜面金属、宝石玻璃、塑料高光、3D 浮雕、厚卡侧面、透视卡片、实体 mockup、手持卡牌、桌布、包装盒、摄影写实、动漫脸、可爱 Q 版、现代服装、蒸汽朋克齿轮堆砌、星盘文字、黄道符号堆砌、随机装饰字符、标题、编号、水印、额外卡牌、拼贴多格、重复人物、畸形手指、漂浮道具、核心象征缺失、把参考图的隐士复制到非隐士牌、直接复制任何现有商业塔罗牌构图。

## 统一构图参数

- 画布：1024×1536 PNG，2:3；
- 镜头：正视，近似 50–70 mm 的平稳观察感，无广角畸变；
- 主体：位于中央视觉区，最大轮廓不得被裁切；
- 安全区：顶部 138 px、底部 215 px 不放关键细节；
- 金色覆盖：建议占有效画面 8%—15%，不能全图平均发亮；
- 颗粒：手机屏幕可见但不糊脸、不吞没手势和小道具；
- 光源：每张只设一个叙事性主光源，避免舞台灯与高光泛滥；
- 人物：手部、持物关系、视线和身体重心必须符合牌义；
- 原创：可保留主流塔罗的必要语义符号，但重新设计服装、建筑、纹样、姿态细节和空间关系。

## 批次一致性锁定

六张试产通过后，固定并记录：模型版本、画布比例、参考图顺序、公共前缀、负面 Prompt、随机种子（若工具支持）、颗粒强度、金色占比、人物尺度与明暗曲线。后续只替换牌义块，不临时增加新的风格形容词。

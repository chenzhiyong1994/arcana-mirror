# 22 张大阿尔卡那牌义 Prompt

## 使用方式

每张牌的最终 Prompt 按以下顺序拼接：

1. `STYLE_A_MASTER_PROMPT.md` 的“牌面插画统一 Prompt”；
2. 本文件中对应牌的“牌义块”；
3. `STYLE_A_MASTER_PROMPT.md` 的“全局负面 Prompt”。

不得把多张牌义块同时提交给生图模型。每次只生成一张牌。

# 统一公共资产提示词

公共资产必须先于 22 张牌面完成。它们只生成一次，不能逐牌变化。

## 1. 统一正面框 `front-frame-overlay.png`

### Prompt

> 参考 `references/style-a-front-back-reference.png` 的 A“仪式典藏”视觉语言，设计一份原创、全套共用的塔罗卡正面框透明叠加层。竖版 2:3，1024×1536，严格正视、无透视。使用煤黑纤维纸质感与克制旧金细线：四层发丝外框、浅建筑拱券轮廓、极简山峰和灯火角章、顶部空白编号牌、底部空白标题铭牌。中央插画窗口必须完全透明，顶部编号牌和底部标题牌不得包含任何字符。边框左右镜像，线条在手机缩略图中不粘连，旧金呈不均匀断箔而非亮黄金属。输出 RGBA PNG，框外与中央窗口透明，禁止人物、场景、卡牌文字、伪文字、阴影、厚度、透视、额外卡片和背景 mockup。

### 确定性处理要求

生图结果只能作为边框母版。交付前必须用图像工具清理为真正透明的 RGBA 层，并确保四边位置固定。若模型无法可靠输出透明通道，应先输出黑底母版，再通过确定性抠图/矢量重建得到透明层，不能把黑底当透明层交付。

## 2. 统一卡背 `card-back.png`

### Prompt

> 参考 `references/style-a-front-back-reference.png` 右侧卡背的材质与层级，设计一张原创、全套唯一的塔罗卡背。竖版 2:3，1024×1536，严格正视、平面、无文字。煤黑和石墨灰纤维纸为底，不均匀旧金细线组成四层边框、中央暗色椭圆镜、原创六芒灯星与四向光线，少量星尘只用于填充节奏。结构必须同时满足水平镜像、垂直镜像和旋转 180° 后完全不可辨方向；四个角章完全一致；上半部与下半部不得出现独有符号。旧金哑光、断箔、非亮黄铜。禁止标题、编号、字符、人物、太阳/月亮方向标记、上下不对称、实体卡片 mockup、透视、厚度、桌布、包装和额外卡牌。

### 确定性处理要求

模型生成后，只取一个经过验收的象限，以确定性镜像方式重建整张卡背；不得仅凭肉眼判断模型图“看起来对称”。最终对成品执行水平翻转、垂直翻转和 180° 旋转像素差检查。

## 3. 预览合成规则

- 先放置 `faces/*.png`；
- 再叠加唯一 `front-frame-overlay.png`；
- 最后用确定性字体排版编号、中文名和英文名；
- 不修改纯插画原文件；
- 预览文字只用于验收和展示，正式小程序仍由前端叠加。

# 小程序 Logo 视觉候选

> 当前状态：L5“繁饰日蚀心镜”已于 2026-07-22 确认为小程序 Logo；L1—L4 保留为探索记录，不再参与定稿。

## 共同生成约束

- 生成方式：会话内置 `image_gen`，未使用外部 CLI/API 通道；
- 视觉参考：`assets/tarot-card-style/concepts/style-concept-a-ritual-archive-v1.png`，只继承煤黑、石墨灰、旧金、哑光纸张与典藏气质；
- 品牌语义：以“心镜、内在照见、引导之光”为核心，不复制隐士、塔罗卡框、标题或卡背；
- 使用场景：微信小程序头像，1:1，圆形或圆角方形裁切后仍可辨认；
- 共同禁止：文字、字母、人物、实体卡片、手持 mockup、水印、星盘堆砌、霓虹与复杂小细节；
- 原始生成图为 1254×1254；为了满足大于 2MB 的交付要求，使用高质量双三次插值统一输出为 2048×2048 PNG，不改变构图与内容。

## L1：极简镜焰

![L1 极简镜焰](logo-l1-minimal-mirror-flame-v1.png)

- 文件：`logo-l1-minimal-mirror-flame-v1.png`
- Prompt 摘要：用粗壮近圆镜环与中央负形火焰组成不可拆分的单一标志；环体由垂直反射缝切开，中心只保留一枚暖白火种；采用现代几何矢量语言、煤黑底与哑光旧金，标志占画布约 68%，禁止细线和装饰星点。
- 优势：四个方案中缩略图识别最稳，结构直接，最接近可实际使用的 App 图标。
- 风险：圆环加火焰的母题较常见，若定稿需要在切口比例或火焰负形上建立更独特的品牌特征。
- 验收：正方形、无文字、无 mockup、小尺寸轮廓与大于 2MB 通过；原创差异性待定稿强化。

## L2：秘仪日蚀

![L2 秘仪日蚀](logo-l2-eclipse-seal-v1.png)

- 文件：`logo-l2-eclipse-seal-v1.png`
- Prompt 摘要：以完整暗色日蚀圆盘、偏置旧金反射弧和交点四芒光组成紧凑圆形印记；用两段相向弧线暗示镜面向内开启，保留古典蚀刻和断金墨质感，但禁止黄道、月相、五芒星和钱币 3D。
- 优势：神秘感、仪式感和视觉记忆点最强，与 A 卡牌风格衔接自然。
- 风险：气质偏冷峻，可能被理解为日蚀、瞄准镜或科幻组织徽记，亲和力弱于 L3。
- 验收：正方形、无文字、无 mockup、结构完整与大于 2MB 通过；品牌语义区分度需用户判断。

## L3：现代光镜

![L3 现代光镜](logo-l3-luminous-inner-mirror-v1.png)

- 文件：`logo-l3-luminous-inner-mirror-v1.png`
- Prompt 摘要：两条镜像流线向内形成接近心形但不直接画爱心的镜面开口，中央悬浮暖金光种，底部一条柔和反射线表现“照见自己”；采用现代数字品牌语言、深石墨与克制香槟金柔光。
- 优势：第一眼吸引力、亲和力和消费级 App 感最强，能够弱化传统塔罗的距离感。
- 风险：当前图四角出现白色圆角外缘，不能直接作为正式资产；部分流线缩小后可能接近冥想或美容品牌。
- 验收：正方形、无文字、小尺寸主体与大于 2MB 通过；全幅深色背景不通过，选中后必须定向修订。

## L4：手工符印

![L4 手工符印](logo-l4-hand-cut-sigil-v1.png)

- 文件：`logo-l4-hand-cut-sigil-v1.png`
- Prompt 摘要：用不规则粗粝圆形镜痕、下缘切出的火焰和一条打破圆环的斜向反射光组成手工符印；采用木刻/版画与断裂金箔，保留非完美但有控制的作者感，禁止维多利亚细饰和完美计算机几何。
- 优势：原创气质、手作感与文化品牌感最强，不像通用科技或占卜应用图标。
- 风险：斜线可能被看作笔尖、指南针或书法标志；粗粝程度也可能削弱产品的精致感。
- 验收：正方形、无文字、全幅背景、小尺寸主形状与大于 2MB 通过；语义准确性待用户选择。

## L5：繁饰日蚀心镜

![L5 繁饰日蚀心镜](logo-l5-ornate-eclipse-mirror-v1.png)

- 文件：`logo-l5-ornate-eclipse-mirror-v1.png`
- 参考来源：用户提供的即梦生成图，仅作为本轮重绘的构图与手绘质感参考；原参考图未复制进仓库。
- Prompt 摘要：保留完整暗色日蚀圆盘、右侧偏置椭圆古镜、交点星芒、多层旧金边框和大师手绘式卷草纹；逐一重绘花纹节奏与连接关系，修正断线、粘连、摄影反光、桌面背景、脏污和失控颗粒，明确禁止扁平矢量、极简几何和卡通平滑。
- 优势：保住原参考图的繁复工艺感与收藏感，古镜成为明确的“心镜”语义核心；主圆盘、镜片和星芒在小尺寸下仍能形成稳定轮廓。
- 风险：装饰密度明显高于常规 App 图标；缩小时卷草纹会退化为金色肌理，但不影响主结构识别。椭圆镜仍带少量实物质感，需要用户判断这是否正是期望的品牌气质。
- 验收：2048×2048 PNG、9.1MB、正方形、无文字、无桌面 mockup、全幅深色背景通过；用户已确认作为小程序 Logo 使用。

## 定稿结论

- L5“繁饰日蚀心镜”作为正式 Logo；
- L1—L4 仅作为探索记录保留；
- 后续尺寸适配只能调整画布、留白与导出规格，不得把卷草纹、层叠旧金边框或椭圆古镜改成平滑卡通简笔画。

## 当前状态

视觉探索已收敛为两个备选方向，尚未确定正式主视觉，也未启动 22 张牌批量生成：

1. **A：仪式典藏**——黑灰手工版画、纤维纸、不均匀旧金箔与精细仪式边框；

## 共同牌义基准

隐士牌必须表现一位年长隐士独自在高山上低头沉思，一手提含六芒星光的灯，一手持长杖。人物、灯、手、杖与山峰关系必须清楚，不能替换成远方灯火、独立悬浮物、微小旅人或第二人物。

后续每张牌都先定义并验收牌义层，再应用 A 或 G 的视觉层；核心人物、道具、姿态或象征缺失即不通过。

## 正反面与前端分层

正式资产必须拆成四层：

1. 每张牌独立生成的牌面插画层；
2. 全牌组共用的确定性正面边框层；
3. 由前端叠加的编号与中英文标题层；
4. 一张严格双轴与 180° 对称的统一卡背。

翻牌动效只在正面层与统一卡背层之间切换；卡背不按卡牌重新生成，生成图片中的示意文字不进入正式资产。

## 后续门禁

1. 用户明确选择 A、G 或提出新的探索方向；
2. 先制作一张最终隐士基准与一张独立卡背；
3. 验证缩略图、文字叠加、翻牌与正逆位；
4. 确认后再固化生成合同并扩展牌组。

# 阿卡纳心镜：塔罗卡片风格基准

## 本轮目的

用同一“提灯者”主题、相同卡片比例和相近构图测试四种视觉语言，只比较色彩、材质、边框与插画气质，不同时引入品牌名、卡牌标题、页面 UI 或动效变量。

## 已确定主视觉

项目以 `style-hermit-v3.png` 作为主视觉基准：采用 A 方向演进后的黑灰手工版画、纤维纸和不均匀旧金箔，同时使用符合主流塔罗认知的牌面形象与可复用边框系统。四方案对照图与 V2 保留为决策过程，不作为后续生成基准。

## 正反面与收藏感探索

2026-07-19 新增三组“正面 + 统一卡背”概念样张，探索名称排版、精致边框、翻牌前卡背识别和收藏感。当前处于用户选择阶段，尚未替换 `style-hermit-v3.png`，也未启动 22 张牌批量生成。样张、Prompt 和验收记录见 [`concepts/README.md`](concepts/README.md)。

## A 方案参考图修订

- 文件：`style-a-reference-v2.png`
- 参考输入：用户提供的黑灰颗粒、金色路径与孤独人物构图参考
- 使用方式：仅作为风格与材质参考，重新设计路径、人物、山体、灯笼和边框关系
- 修订结果：从“精密天体线刻”转向“黑灰版画颗粒 + 不规则旧金箔 + 极细几何边框”
- 可继承基准：煤黑/石墨灰/旧金三色；纤维纸、刮擦、油墨晕染和不均匀金箔；小人物与单一发光物作为叙事锚点
- 不应固化：金色道路只适合部分卡牌，整套牌应根据各自象征重新设计主形状

V2 只验证了视觉材质，构图不符合“隐士本人提灯、持杖”的主流牌面认知，不作为角色构图基准。

## 隐士牌面基准 V3

- 文件：`style-hermit-v3.png`
- 牌面识别：年长隐士位于高山顶端，披深色斗篷，低头沉思；一手明确提灯，灯内含六芒星光；另一手明确持长杖
- 构图规则：人物为中央主体，占画面高度约 55%—65%；灯、手、杖关系必须清晰，不能把灯变成远方目标或独立悬浮物
- 边框规则：双线旧金边框、对称角饰、顶部编号区、底部标题铭牌、独立主体画框；编号和标题由前端叠加
- 风格继承：黑灰手工版画、纤维纸、颗粒油墨、刮擦和不均匀旧金箔

## 牌组生成合同

后续每张牌分成两个独立输入层，禁止互相替代：

1. **牌义层（先锁定）**：按主流塔罗认知列出人物、道具、姿态、场景和关键象征；生成后逐项验收，缺少核心道具即判定失败。
2. **视觉层（后应用）**：只控制黑灰旧金配色、手工版画材质、光感和统一边框，不从风格参考图继承具体人物关系或场景构图。

牌组共用的边框、人物尺度、留白和颗粒强度应保持一致；每张牌的主体形象与核心象征必须单独定义，不能套用“人物走向某个发光物”的通用模板。

## 后续生成基准

1. 卡片成品统一使用 2:3 竖版比例；
2. 同一批次固定边框结构、视觉重心、人物尺度和材质颗粒；
3. 卡牌标题、编号和解释文字由前端排版，不交给生图模型；
4. 每次先生成单张基准牌并确认，再扩展同风格牌组；
5. 保持原创，不模仿现有塔罗牌组或具体艺术家；
6. 评审维度固定为：缩略图识别、主体清晰、品牌差异、批量一致性、动效适配、分享传播力。

## 本轮 Prompt 摘要

生成一张横向四卡对照图，四张完整 2:3 竖卡采用相同“提灯者走在山路上”的主题、尺寸和正视构图；分别应用深夜鎏金、月光晶体、东方矿彩、柔雾拼贴四种原创视觉语言。禁止品牌、标题、编号、水印、透视 mockup、裁切和额外卡片。

参考图修订 Prompt：以用户图片作为风格和材质参考，吸收手工黑金版画、颗粒油墨、旧金箔、强路径引导和微小人物的语言；生成原创 2:3 竖卡，以新的非对称路径、山体和灯笼布局表现“朝向光前行”，保留极细鎏金边框，不复制参考图文字、符号或具体构图。

隐士 V3 修订 Prompt：保留既定黑灰旧金版画语言，完全替换道路构图；锁定一位年长隐士作为中央主体，在高山顶端一手提含六芒星光的灯笼、一手持杖，使用可复用的顶部编号区和底部标题铭牌，禁止远方灯笼、道路、微小旅人和第二人物。
